# GALAPAGOS お金の使い道

自分の資金の使い道を、分類・項目と利用月で記録するツールです。事業経費・税務上の必要経費の判定は行いません。

## 起動

Node.js 24以上が必要です（ローカルDBは `node:sqlite`）。

```bash
npm ci --cache /workspace/.npm-cache
cp .env.example .env.local # 初回のみ。既存設定は上書きしない
npm run dev
```

開発サーバーはループバックのポート3000で起動します。`GALAPAGOS_LOCAL_MODE=1` は認証を省いた単独開発専用です。公開サーバーでは使用できず、本番モードでは明示的に拒否されます。

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e # Chromium が必要。CHROMIUM_PATH で実行ファイル指定可
```

## 基本の使い方

1. カード・銀行などのサイトからCSVを取得し、金融サービスとファイルを選んで取り込みます。
2. 対象年を選び、各明細の「振り分け項目」を選択します。選択した項目は結果シートに即時反映し、同じ利用先の全明細（別年度・別サービスを含む）にも適用します。今後の取込にも同じ項目を適用します。保存に失敗した場合は元の表示に戻ります。
3. 「振り分け結果を確認・出力」の表でExcelと同じ項目・並び順・金額を確認し、「Excelをダウンロード」で対象年の項目別明細を取得します。Excel上で項目を変更することもできます（アプリへの再取込はありません）。

普段の操作はこの1画面で完結します。文字コード、複数口座の別名、手数料、列名の対応は「読み込み設定」にまとめています。CSVの自動取得は行いません。

Excelは「年間_項目別（分類・項目 × 1〜12月＋年間合計）」と12か月の明細シートです。画面でもシートを切り替えて確認できます。添付された2025年の利用明細Excelと項目表記を合わせています。過去の固有項目・独自追加項目も保持します。

集計は利用日が基準です。税金・保険・投資・借入元本返済・未判定の銀行出金も個人の資金用途として含め、返金は返金月に減算します。カード引落・自己口座振替・チャージ・入金・引落不能・取消・重複除外は年間表に加算しません。月別明細には対象外の行も残し、理由と集計額を表示します。未判定の取引や分類は確認が必要です。分類・取込時のGoogle Sheets自動同期は行いません。

既存データ・認証・CSV検証・重複取込防止は保持しています。従来の管理APIと詳細Excel出力は互換性のため残していますが、通常画面には表示しません。

## 検証の境界

実サービスの公式CSVサンプル・接続権限は未提供です。`public/samples/` はすべて**架空の検証データ**であり、各社の現在の公式CSV形式と一致するという主張ではありません。実CSVで列対応と金額を確認してください。金融APIの架空エンドポイントやパスワード保存・スクレイピングはありません。

Google実アカウント・Supabase実プロジェクトでの接続試験は未実施です。Sheets APIはモック試験、永続化と画面は実SQLite/Chromiumで検証します。既存売上コードは空のリポジトリに存在しなかったため、売上ツールの回帰試験は実行できません。
